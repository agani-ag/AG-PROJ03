What the admin can see

stated here so it is not a surprise

Every message of every chat is readable from this console, and the Self-ID of every account is stored in a form its owner can read back — which means it is readable here too, and inside any database backup you download. J6 is not private from its own admin and does not claim to be: the welcome screen says so in one line before anyone starts.
